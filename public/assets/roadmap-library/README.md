# Bob Roadmap Asset Library

Place approved local assets for roadmap pages here. Gemini may select a registered asset key, never an arbitrary file path or remote URL.

Organization:
- `tools/` — product/tool logos (ChatGPT, Claude, Gemini, GitHub, VS Code, Notion, Google Docs/Sheets, Figma, Excel, Gmail, etc.). Prefer SVG or transparent PNG.
- `illustrations/` — small decorative illustrations for intro / reveal / “did you know” pages.
- `patterns/` — subtle backgrounds or textures; prefer flat dark canvas when the page reference calls for it (avoid heavy gradients).

Register every asset by a fixed key in code before the model can use it.
Never accept model-generated HTML, CSS, paths, or executable code.
