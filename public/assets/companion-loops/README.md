# Bob Companion Overlay Loop Videos

Place short looping WebM/MP4 clips here for Bob’s floating overlay bubble.

Expected keys (file names):
- `bob-idle.webm` — calm idle presence
- `bob-listening.webm` — listening / attentive
- `bob-thinking.webm` — thinking / processing
- `bob-speaking.webm` — speaking / responding

Keep clips short (2–6 s), transparent or dark-friendly background, 256–512 px square preferred.
The overlay will fall back to the static orb image if a file is missing or fails to load.
